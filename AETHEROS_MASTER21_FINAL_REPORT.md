## Methodology

- Same task text per task for every agent (P5); identical deterministic
  validators score all agents (P44).
- Fairness fingerprint over model/provider/reasoning/tools/dataset/
  benchmark-version; mismatches emit FAIRNESS_WARNING and comparisons get
  labeled NOT_DIRECTLY_COMPARABLE (P4, P19-20, P44).
- BLOCKED executions preserved with reasons (P9/P12): agents not on PATH,
  live-execution disabled, capability unavailable.
- FALSE_DONE derived: agent claimed completion + validator failed (P16) —
  surfaced everywhere, never averaged away.
- Claims generator emits INSUFFICIENT EVIDENCE rather than marketing
  language when evidence is missing (P62/63).
