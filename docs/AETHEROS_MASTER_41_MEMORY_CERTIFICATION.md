## Architecture

Layers L0–L10 in `layers.py`; retrieval pipeline
intent→scope→entity→temporal→channels→fusion→rerank→conflict→freshness→
budget (`hybrid.py`); graph in `graph_store.py`; consolidation/dreaming in
`writer.py` (proposals only, preferences never auto-created); conflicts
newest-explicit-confirmed-wins with supersede chains.
