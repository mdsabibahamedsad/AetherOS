# AetherOS 1.0 Support Model

Channels: in-app support bundle export (redacted), bug/feedback/feature
intake with severity P0–P3, security contact (reporting channel documented at
launch; no private creds exposed). Response: SEV0–SEV3 incident flow
(detect→triage→contain→eradicate→recover→communicate→postmortem). Supported
versions policy: current + previous + security window; vulnerable olds
revocable; EOL deadlines published per platform. On-call and escalation exist
on paper (runbook) — live operation UNVERIFIED until launch.
