# AetherOS Production User Guide (1.0 — pre-launch)

Installation/login/agent/browser/computer-use/memory/automation/research/
swarm: follow in-app onboarding, which explains permissions, privacy, agent
autonomy levels (MANUAL/ASSISTED/SUPERVISED/AUTONOMOUS), and computer-use
implications. High-risk actions always require approval; you always know when
the agent acts, the computer is controlled, the screen is shared, or data is
uploaded. Updates show version/size/reason/restart impact and respect
metered/battery/active-task policy. Privacy controls: telemetry opt-out,
export/delete, memory clear, device revocation. Support: export the redacted
support bundle and follow the severity scale (P0–P3). No deceptive UI is
tolerated — report any.
