# AetherOS Brand Radius System

Controlled radius language (`design-system/tokens/radius.ts`): Small 4px,
Medium 6–8px, Large 12px, XL 16–24px, Pill 9999px. Semantic stops —
button, input, card, dialog, popover, tooltip, badge, avatar, focus-ring —
are the only radii new components may use. The wolf tile uses 12px
(`BRAND.cornerRadius`); lockup mono tiles use 22%. No random corner radii.
