# AetherOS Schema Reference

Schema version `1.0.0` — single source of truth in `aetheros_platform/schemas.py`. TypeScript bindings are generated by `aetheros_platform/tsgen.py` (never hand-edited).

## `APIKey`

Required: `name`

- `name`: string
- `scopes`: array
- `expiresInDays`: integer

## `Agent`

Required: `name`, `version`

- `name`: string (pattern `^[a-z0-9][a-z0-9-_]*$`)
- `version`: string (pattern `^[0-9]+\.[0-9]+\.[0-9]+$`)
- `description`: string
- `capabilities`: array
- `inputs`: object
- `outputs`: object
- `tools`: array
- `skills`: array
- `models`: object
- `memoryPolicy`: object
- `artifactPolicy`: object
- `networkPolicy`: object
- `filesystemPolicy`: object
- `dataPolicy`: object
- `approvalPolicy`: object
- `resourceLimits`: object
- `tenant`: object

## `AgentCard`

Required: `name`, `version`, `protocolVersion`, `capabilities`

- `name`: string
- `version`: string
- `protocolVersion`: string
- `description`: string
- `capabilities`: array
- `endpoint`: string
- `authentication`: object
- `trust`: string (one of: untrusted, known, trusted)

## `AgentEvent`

Required: `type`

- `type`: string (one of: AgentStarted, AgentCompleted, TaskCreated, TaskUpdated, ToolInvoked, ToolCompleted, ApprovalRequested, ApprovalResolved)
- `eventId`: string
- `timestamp`: number
- `source`: string
- `task`: string
- `agent`: string
- `correlationId`: string
- `causationId`: string
- `schemaVersion`: string
- `payload`: object
- `securityClassification`: string (one of: public, internal, confidential)

## `AgentResult`

Required: `taskId`, `state`

- `taskId`: string
- `state`: string (one of: PENDING, RUNNING, WAITING_APPROVAL, PAUSED, COMPLETED, FAILED, CANCELLED)
- `output`: object
- `artifacts`: array
- `usage`: object

## `AgentTask`

Required: `agent`, `input`

- `agent`: string
- `input`: object
- `idempotencyKey`: string
- `model`: object
- `tenant`: object

## `Approval`

Required: `requestId`, `intent`

- `requestId`: string
- `intent`: object
- `status`: string (one of: pending, approved, denied, cancelled, expired)
- `requestedBy`: string
- `resolvedBy`: string
- `resolvedAt`: number

## `Artifact`

Required: `artifactId`, `hash`

- `artifactId`: string
- `hash`: string
- `type`: string
- `size`: integer
- `creator`: string
- `taskId`: string
- `provenance`: object
- `securityClassification`: string
- `parentArtifacts`: array

## `Automation`

Required: `name`, `trigger`

- `name`: string
- `trigger`: object
- `actions`: array
- `enabled`: boolean

## `Capability`

Required: `name`

- `name`: string (pattern `^[a-z0-9]+\.[a-z0-9_]+$`)
- `risk`: string (one of: LOW, MEDIUM, HIGH, CRITICAL)
- `description`: string

## `CredentialReference`

Required: `reference`

- `reference`: string (pattern `^cred://[A-Za-z0-9/_-]+$`)
- `scope`: string

## `Device`

Required: `deviceId`

- `deviceId`: string
- `kind`: string
- `owner`: string

## `Error`

Required: `category`, `message`

- `category`: string
- `message`: string

- `retryable`: boolean
- `requestId`: string
- `remediation`: string

## `Extension`

Required: `name`, `version`, `entrypoint`

- `name`: string (pattern `^[a-z0-9][a-z0-9-_]*$`)
- `version`: string (pattern `^[0-9]+\.[0-9]+\.[0-9]+$`)
- `entrypoint`: string
- `permissions`: array
